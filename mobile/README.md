# App mobile

App React Native + Expo (SDK 57) com Expo Router. As instruções para rodar estão no
[README da raiz](../README.md).

- Telas ficam em `src/app/` (cada arquivo é uma rota).
- Componentes, hooks e utilitários ficam em `src/`, fora de `src/app/`.
- O endereço da API vem de `EXPO_PUBLIC_API_URL`, definido em `.env`.
